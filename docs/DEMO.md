# TRIM — Official 60–90 Second Demo Script

This document details the exact script and flow for demonstrating TRIM in a live presentation or video showcase.

---

## The Demo Concept
$$\text{CHAOS} \longrightarrow \text{AI} \longrightarrow \text{TRIM} \longrightarrow \text{MVP} \longrightarrow \text{LOCK} \longrightarrow \text{BUILD}$$

---

## Sample Demo Idea (Bloated Chaos)

> *"An AI-powered productivity super-app with habit tracking, pomodoro timers, crypto staking for streaks, an integrated social network for founders, direct messaging, web3 NFT avatars, and full enterprise team permissions."*

---

## 60–90 Second Demonstration Timeline

| Time | Action / Screen | Visual / Audio Cue |
| :--- | :--- | :--- |
| **00:00 - 00:10** | **1. Open TRIM** | App opens with OLED black aesthetic and tactile spring physics. |
| **00:10 - 00:25** | **2. Brain Dump (Speak or Type)** | Tap **SPEAK** (or tap sample text). Dictate the bloated productivity app idea. Watch real-time transcript populate. |
| **00:25 - 00:30** | **3. Review Transcript** | Show that the user has complete control to inspect or edit the idea before submission. |
| **00:30 - 00:35** | **4. Tap "TRIM THE FAT"** | Strong tactile click. Single-tap triggers triage. |
| **00:35 - 00:45** | **5. Processing Transformation** | Showcase the 4-phase radar animation: `AUDITING_SCOPE` $\rightarrow$ `EXTRACTING_ESSENCE` $\rightarrow$ `SEVERING_BLOAT` $\rightarrow$ `SYNTHESIZING_MVP`. |
| **00:45 - 00:55** | **6. Verdict & Scope Severance** | Verdict lands. Highlight **MVP Score (e.g., 92)**. Highlight scope reduction metric: **7 features submitted $\rightarrow$ 1 survivor**. |
| **00:55 - 01:05** | **7. Core vs. Noise Breakdown** | - **Must Haves**: Daily habit tracker with core feedback loop.<br>- **Discarded Bloat**: Expand crypto staking, social network, and NFT avatars. Read the brutal justifications. |
| **01:05 - 01:15** | **8. Build First & Product Truth** | - **Build First**: Show Step 01 engineering roadmap.<br>- **Product Truth**: Read the harsh reality check: *"Validate the core habit loop before adding a crypto economy."* |
| **01:15 - 01:22** | **9. Lock MVP** | Tap **LOCK MVP**. Scope freezes to prevent feature creep. Saved to local history. |
| **01:22 - 01:30** | **10. Send to Build Desk** | Tap **SEND TO BUILD DESK**. Laptop receives `MVP_SPEC.md`, `BUILD_ORDER.md`, `CUT_FEATURES.md`, and `PRODUCT_TRUTH.md`. Cross-device handoff complete! |

---

## Key Takeaway for Judges
> *"TRIM solves founder delusion. The phone is where you plan and cut the fat; the laptop is where you execute."*
